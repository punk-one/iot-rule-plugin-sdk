# Security Policy

## Supported versions

Security fixes are provided for the latest `v1.x` release throughout the
36-month compatibility period documented in
[`docs/v1-compatibility-policy.md`](docs/v1-compatibility-policy.md).

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting feature for this repository and include:

- affected SDK, engine and plugin versions;
- reproduction steps or a minimal proof of concept;
- expected impact and any known mitigations;
- whether credentials or production data may have been exposed.

Maintainers should acknowledge a report within five business days. Public
disclosure and release timing will be coordinated with the reporter whenever
possible. Never include real credentials, tokens or private keys in a report.
